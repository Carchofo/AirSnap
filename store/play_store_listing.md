Turn any Bluetooth device into a camera shutter — no extra hardware needed.

## Accessibility Service Declaration (for Google Play review)

**Why AirSnap uses the Accessibility Service:**

AirSnap requires the Android Accessibility Service exclusively to intercept hardware key events (button presses) generated by Bluetooth peripherals such as headsets, smartbands, and remote controls. This is the only Android API capable of reliably capturing key events from all Bluetooth HID and media devices regardless of their profile or manufacturer.

**What AirSnap does NOT do:**
- Does not read screen content
- Does not access any UI elements or text fields
- Does not collect, store or transmit any user data
- Does not monitor any apps or user activity
- Does not perform any action other than triggering the camera shutter

**There is no less-invasive alternative:**
Standard key event APIs (dispatchKeyEvent, MediaSession) do not capture button presses from Bluetooth devices using proprietary protocols (touch-based earbuds, smartbands, etc.). The Accessibility Service is the only reliable cross-device solution without requiring device-specific integrations.

**User disclosure:**
Before enabling the Accessibility Service, AirSnap displays a prominent in-app notice explaining exactly what the permission is used for. The user must explicitly activate it in Android Settings.
